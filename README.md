# Nancy Yadav — Portfolio (React + Vite)

Dark, techy, responsive portfolio website built with React and Vite.
Tailwind utilities are provided via the Play CDN for convenience.
Framer Motion is used for subtle animations.

## Quick start

1. Extract the zip.
2. `cd nancy-portfolio`
3. `npm install`
4. `npm run dev`
5. Open http://localhost:5173

Note: Tailwind is loaded from CDN (no Tailwind build required). Framer Motion is listed in dependencies.
